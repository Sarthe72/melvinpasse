# Scoring candidature

## Scores 0-100
- `profile_fit` 45% : correspondance missions/compétences/preuves.
- `personal_fit` 35% : adéquation avec les préférences de poste.
- `opportunity_fit` 20% : niveau de responsabilité, intérêt/ampleur du projet, progression possible, secteur/contexte si identifiable.

## Confiance
Afficher séparément `confidence` selon la quantité de données explicites dans l'offre. Ne jamais transformer une absence d'information en hypothèse positive.

## Recommandation
- GO : score global >= 75 et aucun red flag bloquant.
- À ÉTUDIER : 55-74 ou information critique manquante.
- NO GO : <55 ou red flag bloquant clairement établi.

## Red flags configurables
- rémunération explicitement très inférieure à la cible ;
- samedi régulier imposé ;
- rôle sans autonomie alors que cela ressort explicitement ;
- responsabilité très inférieure au positionnement cible ;
- contrainte géographique incompatible explicitement établie.

Chaque score doit afficher les éléments qui l'expliquent. Pas de pourcentage décoratif sorti d'un chapeau algorithmique.
